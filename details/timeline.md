### **🗓️ ไทม์ไลน์ 6 สัปดาห์: AI Accounting Copilot (อิงโครงสร้าง Eigent \+ Python Backend)**

ในแต่ละฟีเจอร์ อยากให้ออกแบบmulti agentด้วย เช่น **Feature 1 \- Meter Reader Copilot** ให้ตัวนึงหา,ย้ายรูปมิเตอร์จากfolder downloadไปไว้ในfolderที่เราต้องการให้ใช้เป็นที่เก็บรูป จากนั้นให้อีกตัวดึงรูปไปocr จากนั้นให้อีกตัวเอาผลลัพท์ใส่excel,ใส่รูป จากนั้นให้อีกตัวมาทำหน้าที่ตรวจสอบความถูกต้อง ไรงี้  
**สัปดาห์ที่ 1: Foundation & Thai Localization (เตรียมฐานรากและปรับภาษา)**

* **งานหลัก:** ติดตั้ง Eigent ให้รัน Local ได้สมบูรณ์  
* **Frontend:** เข้าไปปรับแก้ไฟล์ภาษา (Locale) ของ Eigent เพื่อเปลี่ยนเมนู แชท และปุ่ม UI ต่างๆ ให้เป็นภาษาไทยทั้งหมด เพื่อให้พนักงานบัญชีใช้งานง่าย  
* **Backend:** เตรียมโฟลเดอร์สำหรับรับรูปมิเตอร์ และทดสอบเขียนโค้ด Python เบื้องต้นในการเปิดไฟล์ .xlsx ต้นฉบับของบริษัท (ทดสอบให้ชัวร์ว่าเซฟแล้วพวกแถบสีหรือการผสานเซลล์ไม่พัง) (ตรงนี้อาจใช้skillของeigent เรื่องxlxsเข้ามาช่วย)  
* เพิ่มคอลัมน์ **"LINE User ID"** เตรียมไว้ในฐานข้อมูลลูกค้า (ตอนนี้ปล่อยว่างไว้ก่อนได้ แต่เตรียมโครงสร้างเผื่ออนาคต) (หรือจะออกแบบยังไงดี ให้รองรับการส่งไลน์อัตโนมัติในอนาคต)

**สัปดาห์ที่ 2: Feature 1 \- Meter Reader Copilot (AI อ่านภาพและจัดการ Excel)**

* **AI Vision:** เขียนสคริปต์ Python เรียกใช้ Claude Vision API (หรือ GPT-4o หรือตัวอื่น หรือมีmcpหรือskillอะไรมั้ยที่ช่วยตรงนี้ได้) ให้อ่านตัวเลขจากรูปถ่ายมิเตอร์  
* **Calculation Engine:** เขียนลอจิกคูณสูตร (น้ำ 20, ไฟ 7, ภาษีที่ดิน 70/50)  
* **Excel Automation (ไฮไลต์):** ใช้ไลบรารี openpyxl (ตรงนี้อาจใช้skillของeigent เรื่องxlxsเข้ามาช่วยด้วย)  สั่งให้ระบบเปิดไฟล์ Excel เดิมของบริษัท \-\> กรอกตัวเลขลงไปในเดือนที่ถูกต้อง \-\> **ทำการย่อขนาดรูปภาพมิเตอร์และวางแปะลงในเซลล์ Excel ให้ตรงกับชื่อร้านค้านั้นๆ** \-\> บันทึกไฟล์ทับ 

**สัปดาห์ที่ 3: Feature 2 \- Invoice Draft Copilot & FlowAccount MCP**

* **Integration:** นำ Source Code ปลั๊กอิน [https://github.com/todsawat/FlowAccountMCP](https://github.com/todsawat/FlowAccountMCP) มาติดตั้งใน Eigent และดูว่ามันใช้งานได้จริงมั้ยอะไรยังไง  
* **Data Flow:** เขียนสคริปต์ Python อีกตัวเพื่อเข้าไปกวาดข้อมูลตัวเลขจากไฟล์ .xlsx (หลังจากที่พนักงานบัญชีตรวจสอบและเซฟแล้ว) (ส่วนที่เกี่ยวกบxlxsแบบนี้อาจใช้skillของeigent เรื่องxlxsเข้ามาช่วยด้วย)  
* **Action:** แปลงข้อมูลจาก Excel เป็นรูปแบบ JSON แล้วยิง API ผ่าน MCP เพื่อสั่งสร้าง Draft Invoice ในระบบ FlowAccount

**สัปดาห์ที่ 4: Human-in-the-loop (จุดตรวจสอบโดยมนุษย์ผ่านแชท Eigent)**

* **Workflow:** ใช้ฟีเจอร์ Native UI ของ Eigent ตั้งค่าการพูดคุย เช่น เมื่อ AI ทำ Excel เสร็จ ให้ส่งข้อความแจ้งเตือนในแชทว่า *"อัปเดตไฟล์ Excel ประจำเดือนและวางรูปมิเตอร์เรียบร้อยแล้ว กรุณาเปิดไฟล์เพื่อตรวจสอบ"*  
* **Approval Gate:** ระบบจะหยุดรอทำงาน (Pause) จนกว่าพนักงานบัญชีจะดูไฟล์ Excel เสร็จแล้วกลับมากดปุ่ม **\[ ✅ อนุมัติการออกบิล \]** ในหน้าแชท Eigent ตัว Agent จึงจะวิ่งไปทำงานของสัปดาห์ที่ 3 (ยิงเข้า FlowAccount)  
* น่าจะต้องมีตรวจสอบก่อนไม่ก็หลังสร้างinvoice flowaccountเสร็จแล้วด้วยไหม 

**สัปดาห์ที่ 5: Flexible LINE Delivery (ระบบส่งมอบแบบยืดหยุ่น 2 รูปแบบ)**  
ตรงนี้น่าจะต้องทำให้userแก้คำพูดที่ต้องการให้เอาไปส่งไลน์ได้อิสระ เช่น บันทึกไว้ในxlxs เพื่อที่ถ้าuserอยากแก้อะไรจะได้แก้เองได้ แล้วระบบก็มาดึงข้อความกลางนี้ไปใส่ข้อมูลของร้านค้าแต่ละร้านเองไรงี้

* **พัฒนาเงื่อนไข (If/Else Logic) เพื่อรองรับอนาคต:**  
  * **โหมดแมนนวล (Manual):** ถ้ายังไม่มี Token ให้ AI ดึง PDF,รูป (อันนี้น่าจะต้องเพิ่มการทำงานให้exportเป็นรูปด้วย เพราะในrequirementร้านค้าบางร้านต้องการดูเป็นรูปมากกว่าpdf) มาเตรียมไว้ให้ แล้วพ่นข้อความสรุปยอดที่จัดหน้าสวยงาม (Markdown) ลงในแชท Eigent เพื่อให้พนักงานบัญชีใช้เมาส์ Copy ข้อความและลากไฟล์ไปวางส่งใน LINE PC ส่วนตัวได้เลย (จริงๆอันนี้แอบคิดว่าต้องทำui คือให้เป็นแท็บเพิ่มสำหรับเช็คข้อความ จากนั้นจะมีชื่อ,รหัสร้าน และข้างใต้ชื่อจะเป็นข้อความ,รูปภาพ,pdf ที่ข้อคสามจะมีปุ่มให้copy และมาในรูปแบบช่องคือสามารถeditคำได้)  
  * **โหมดอัตโนมัติ (Automated):** เขียนโค้ดดักจับว่า ถ้าระบบมีค่า LINE\_OA\_TOKEN (บริษัทสมัครไลน์ทางการแล้ว) ให้ดึง PDF จาก FlowAccount แล้วยิง API Push Message ส่งหาร้านค้าแต่ละรายโดยตรง (โดยขึ้นuiมาให้เช็คเหมือนเดิม ซึ่งถ้าเค้าจะแก้อะไรก็แก้ แต่ในท้ายที่สุดพอกแก้จนโอเคแล้วก็คือมีปุ่มกดยืนยันในหน้าแชท Eigent เพื่อส่งข้อความอัตโนมัติ ไรงี้)  
* **Testing:** ทดสอบรันระบบแบบ End-to-End ตั้งแต่โยนรูปเข้าโฟลเดอร์ จนถึงการออกบิลและส่งข้อความ

**สัปดาห์ที่ 6: Polish, Edge Cases & Demo Prep (เก็บงานและนำเสนอ)**

* **Bug Fixes:** ทดสอบดักจับ Error ต่างๆ เช่น ช่างถ่ายรูปมิเตอร์มาเบลออ่านไม่ออก (ให้ AI แจ้งเตือนกลับมาในแชทว่า "รูปห้อง V-A1 เบลอ รบกวนขอรูปใหม่ค่ะ")  
* **Documentation:** จัดทำคู่มือการใช้งานสั้นๆ  
* **Presentation:** เตรียมสไลด์สรุป Architecture ที่ออกแบบไว้ และเตรียมทำ Live Demo โชว์การทำงานจริงของระบบให้พี่เลี้ยงและทีมดู
