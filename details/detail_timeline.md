## **สัปดาห์ที่ 1: Foundation & Thai Localization**

**เป้าหมาย:** ติดตั้ง Eigent ให้รันได้สมบูรณ์ \+ เตรียมโครงสร้างข้อมูลทั้งหมด

### **Frontend**

* Clone repo Eigent และรันแบบ Local บนเครื่อง  
* เข้าไปหาไฟล์ locale/i18n แล้วแปลข้อความ UI ทั้งหมดเป็นภาษาไทย ได้แก่ เมนูหลัก, ปุ่ม, ข้อความแจ้งเตือน, หัวข้อแชท  
* ทดสอบว่า UI ภาษาไทยแสดงผล font ถูกต้อง ไม่มีข้อความล้นกรอบ

### **Backend — โครงสร้างโฟลเดอร์** 

จัดโครงสร้างโฟลเดอร์ให้ชัดเจนตั้งแต่ต้น เช่น

/meter-photos/inbox/        ← ช่างโยนรูปมาที่นี่  
/meter-photos/processed/    ← รูปที่ OCR แล้ว  
/meter-photos/archive/      ← รูปที่เสร็จงานแล้ว  
/excel-files/template/      ← ไฟล์ต้นฉบับของบริษัท  
/excel-files/monthly/       ← ไฟล์ที่อัปเดตแล้วแต่ละเดือน  
/output/invoices/           ← PDF/รูป invoice ที่จะส่งลูกค้า  
/config/message-templates/  ← ข้อความ LINE ที่ผู้ใช้แก้ได้เอง  
อาจขึ้นตัวเลือกให้user คือสร้างfolderใหม่ไว้เก็บงานให้user ไม่ก็ให้userบอกpathมาว่าอยากเก็บที่folderไหน (ซึ่งอันนี้น่าจะควรconfigครั้งเดียวแล้วเซฟไว้เป็นdefualt(ถ้าuserอยากเปลี่ยนpathค่อยให้เค้าพิมพ์สั่งเองทีหลัง))

### **Backend — ทดสอบ Excel**

* เขียน Python script ทดสอบเปิด-แก้ไข-บันทึกไฟล์ .xlsx ต้นฉบับของบริษัทด้วย openpyxl  
* **จุดสำคัญ:** ทดสอบว่าหลัง save แล้ว การผสานเซลล์ (merge cells), แถบสี, สูตรคำนวณ ยังคงอยู่ครบ ไม่พัง  
* อ่าน SKILL.md ของ Eigent เรื่อง xlsx เพื่อดูว่ามีฟังก์ชันไหนช่วยได้บ้าง (https://www.eigent.ai/skills/pdf-and-documents/xlsx)

### **Backend — เตรียมฐานข้อมูลลูกค้า**

* เพิ่มคอลัมน์ในไฟล์ข้อมูลลูกค้า ได้แก่ `LINE_USER_ID` (ว่างไว้ก่อน), `DELIVERY_MODE` (ค่าเริ่มต้น: `manual`), `CONTACT_PREFERENCE` (pdf/image/both)  
* โครงสร้างนี้รองรับการส่ง LINE อัตโนมัติในอนาคตโดยไม่ต้องแก้โค้ดใหม่ทั้งหมด

### **ติดตั้ง Plugin เบื้องต้น**

* ติดตั้ง FlowAccount MCP จาก repo ของ todsawat เพื่อทดสอบว่า connect ได้จริง (ยังไม่ต้องใช้งานจริง)  
* ทดสอบ API key ของ Claude Vision หรือ GPT-4o ว่าเรียกได้ปกติ

## **สัปดาห์ที่ 2: Feature 1 — Meter Reader Copilot (Multi-Agent)**

**เป้าหมาย:** ระบบอ่านมิเตอร์ครบวงจร ตั้งแต่รับรูปจนถึงกรอก Excel พร้อมรูป

ออกแบบเป็น **4 Agent ทำงานต่อเนื่องกัน** ดังนี้

---

### **Agent 1 — File Watcher & Mover**

**หน้าที่:** เฝ้าดูโฟลเดอร์ inbox แล้วย้ายรูปไปที่ถูกต้อง

* ตั้ง Trigger ให้ตรวจสอบโฟลเดอร์ `/meter-photos/inbox/` ทุก X นาที หรือ trigger แบบ manual (ที่จริงuserบอกว่าช่างจะถ่ายรูปมาลงอัลบั้มทุกวันที่29-30ของเดือน)  
* เมื่อพบรูปใหม่ ให้อ่านชื่อไฟล์เพื่อระบุห้อง/ร้านค้า (ตกลงกันก่อนว่าช่างจะตั้งชื่อไฟล์ยังไง เช่น `V-A1_water_20250601.jpg`) (ช่างตั้งชื่ออัลบั้มในไลน์เป็น DD/M/YYYY สำหรับมิเตอร์ไฟ และ DD/M/YYYY  \#1 สำหรับน้ำ)  
* ย้ายไปไว้ที่ `/meter-photos/processed/YYYY-MM/` พร้อม log ว่าย้ายไฟล์อะไรไปไหนบ้าง  
* ถ้าชื่อไฟล์อ่านไม่ออก หรือไม่ตรงรูปแบบ ให้แจ้งเตือนในแชท Eigent ทันที  (หรือที่จริง มันเป็นai ฉันว่ามันควรจะวิเคราะห์เองได้ต่อให้formatการตั้งชื่อต่างออกไปจากเดิม ว่าอันนี้น่าจะหมายถึงอะไรไรงี้ แต่ถ้าอันไหนที่ไม่เหมือนหรือวิเคราะห์ไม่ออกจริงๆ ก็ค่อยให้บอก/ถามuser)

---

### **Agent 2 — OCR Reader**

**หน้าที่:** อ่านตัวเลขจากรูปมิเตอร์ด้วย AI Vision

* รับ path รูปจาก Agent 1 \-\> resize ภาพก่อนเพื่อประหยัด token(ยังต้องอ่านตัวหนังสือได้ชัดเจนเหมือนเดิม) แล้วส่งเข้า Claude Vision API (หรือ GPT-4o)   
* Prompt ที่แนะนำ: ระบุให้ชัดว่าต้องการ "ตัวเลขที่แสดงบนมิเตอร์ และชื่อร้าน/รหัสร้านเท่านั้น ไม่เอาอย่างอื่น ตอบเป็น JSON format `{"shop_name": string | null, reading: number, unit: 'water'/'electric', confidence: 'high'/'low'}`"  
* ถ้า confidence \= low (รูปเบลอ, แสงไม่ดี, ตัวเลขบดบัง) → ส่งข้อความแจ้งเตือนกลับมาในแชทว่า "รูปห้อง V-A1 อ่านไม่ออก รบกวนขอรูปใหม่ค่ะ" แล้วหยุดรอโดยไม่ข้ามไป Agent 3  
* บันทึกผลลัพธ์ OCR ทั้งหมดลง JSON file ชั่วคราว เพื่อส่งต่อ Agent 3

---

### **Agent 3 — Excel Writer & Calculator**

**หน้าที่:** คำนวณและกรอกข้อมูลลง Excel พร้อมแนบรูป

**ขั้นตอนการกรอก Excel (สำคัญมาก):**

1. เปิดไฟล์ต้นฉบับด้วย openpyxl  
2. หาเซลล์ที่ตรงกับชื่อ/รหัสร้านค้า \+ เดือนปัจจุบัน  
3. **copy เลขมิเตอร์เดิมไปใส่ช่อง "มิเตอร์ก่อนหน้า"** ก่อน (ตามที่ระบุในขั้นตอนงานจริง) (userบอกขั้นตอนมาว่า (ลบเลขมิเตอร์เดิมให้เป็น 0 ก่อนกรอกเลขใหม่เพื่อเช็คสูตร) (copyเลขมิเตอร์เดิมไปวางช่องหน้า เพื่อเช็คสูตร \-0-) อันนี้ไม่แน่ใจทำยังไง ช่วยดูให้หน่อย)  
4. กรอกเลขมิเตอร์ใหม่ที่อ่านได้  
5. ตรวจว่าสูตรคำนวณทำงาน: หน่วยที่ใช้ \= มิเตอร์ใหม่ \- มิเตอร์เก่า  
6. คำนวณค่าใช้จ่าย: ไฟ × 7, น้ำ × 20, ภาษีที่ดิน 70 หรือ 50 บาท/ตร.ม./ปี ÷ 12 เดือน  
7. ย่อขนาดรูปมิเตอร์แล้ว embed ลงในเซลล์ Excel ให้ตรงแถวร้านค้านั้น  
8. บันทึกไฟล์ทับ (save as ชื่อใหม่ตามเดือน เพื่อป้องกันต้นฉบับพัง)

---

### **Agent 4 — QC Checker**

**หน้าที่:** ตรวจสอบความถูกต้องก่อนส่งต่อมนุษย์

* เปิดไฟล์ Excel ที่ Agent 3 เพิ่งบันทึก แล้วตรวจ:  
  * ตัวเลขมิเตอร์ใหม่ \> ตัวเลขมิเตอร์เก่า (ถ้าไม่ใช่ แสดงว่าผิดปกติ)  
  * หน่วยที่ใช้ไม่สูงหรือต่ำผิดปกติเกินไป (เช่น เกิน 500 หน่วย หรือ 0 หน่วย)  
  * รูปมิเตอร์ถูก embed ครบทุกห้อง  
  * สูตร Excel ยังทำงานอยู่ ไม่มีเซลล์ที่แสดง \#REF\! หรือ \#VALUE\!  
* สรุปผลออกมาเป็นรายงานสั้น แล้วส่งข้อความแจ้งในแชท Eigent ว่าเสร็จแล้ว พร้อมรายการที่ต้องระวัง (ถ้ามี)

## **สัปดาห์ที่ 3: Feature 2 — Invoice Draft Copilot & FlowAccount MCP**

**เป้าหมาย:** ดึงข้อมูลจาก Excel แล้วสร้าง Draft Invoice ใน FlowAccount อัตโนมัติ

### **ทดสอบ FlowAccount MCP**

* รัน FlowAccount MCP server จาก repo ของ todsawat บน local  
* ทดสอบ API แต่ละ endpoint: ดึงรายชื่อลูกค้า, ดูรายการ invoice, สร้าง draft invoice  
* บันทึกว่า field ไหนใน FlowAccount ตรงกับข้อมูลไหนใน Excel ของบริษัท

### **Excel Data Extractor (Python Script)**

* เขียน script อ่านไฟล์ Excel ที่พนักงานบัญชีตรวจสอบและ save แล้ว  
* ดึงข้อมูลแต่ละร้านค้า: ชื่อร้าน, ค่าเช่า, ค่าน้ำ, ค่าไฟ, ภาษีที่ดิน, ยอดรวม, เดือนที่เรียกเก็บ  
* แปลงเป็น JSON format ที่ FlowAccount API รับได้  
* **หมายเหตุสำคัญ:** ค่าเช่า \= ไม่มี VAT, ค่าน้ำ-ไฟ \= มี VAT 7% ต้องแยก line item ให้ถูกต้อง

### **Invoice Creation Agent**

* ออกแบบเป็น **3 Agent** ย่อย:  
  * **Agent A — Data Mapper:** แปลง JSON จาก Excel ให้ตรงกับ schema ของ FlowAccount  
  * **Agent B — Invoice Creator:** เรียก FlowAccount MCP เพื่อสร้าง Draft Invoice (ใช้ Duplicate จากเดือนก่อนถ้า API รองรับ เพื่อประหยัดเวลา)  
  * **Agent C — Verifier:** ดึง invoice ที่เพิ่งสร้างกลับมาตรวจว่า ยอดเงินตรง, ชื่อลูกค้าถูก, เดือนในหมายเหตุถูกต้อง

## **สัปดาห์ที่ 4: Human-in-the-Loop — จุดตรวจสอบโดยมนุษย์**

**เป้าหมาย:** วาง checkpoint ที่ถูกจุด ให้พนักงานบัญชีควบคุมได้ทุก step สำคัญ

ออกแบบให้มี **3 จุด Approval Gate** ในทั้งกระบวนการ:

---

### **Gate 1 — หลัง OCR & กรอก Excel เสร็จ**

ระบบส่งข้อความในแชท Eigent ว่า:

"อัปเดต Excel ประจำเดือน \[เดือน\] เรียบร้อยแล้ว กรอกข้อมูลมิเตอร์ครบ \[X\] ร้าน มีรายการที่ควรตรวจสอบ: \[รายการจาก QC Checker\] กรุณาเปิดไฟล์ตรวจสอบ แล้วกดปุ่มด้านล่าง"

ปุ่มในแชท:

* ✅ **ตรวจสอบแล้ว ออกบิลได้เลย**  
* ✏️ **ขอแก้ไขก่อน** (ระบบหยุดรอ ไม่ทำอะไรต่อ)

---

### **Gate 2 — หลังสร้าง Draft Invoice ใน FlowAccount แล้ว**

ระบบดึงข้อมูล invoice ที่สร้างมาแสดงสรุปในแชท พร้อมข้อความว่า:

"สร้าง Draft Invoice ใน FlowAccount แล้ว \[X\] รายการ ยอดรวมทั้งหมด \[X\] บาท กรุณาเข้าไปตรวจสอบใน FlowAccount แล้วกด Confirm เพื่อดำเนินการต่อ"

ปุ่มในแชท:

* ✅ **Invoice ถูกต้อง ไปขั้นตอนส่ง LINE**  
* 🔄 **พบข้อผิดพลาด ให้ระบบแก้ไข** (ระบุปัญหาในช่อง text แล้ว agent จะไปแก้ให้)

---

### **Gate 3 — ก่อนส่ง LINE ให้ลูกค้า (Gate นี้อยู่ในสัปดาห์ที่ 5\)**

ดูรายละเอียดด้านล่าง

## **สัปดาห์ที่ 5: Flexible LINE Delivery — ระบบส่งมอบแบบยืดหยุ่น**

**เป้าหมาย:** ระบบส่งแจ้งหนี้ทาง LINE ที่พนักงานบัญชีแก้ข้อความได้เอง (ไม่แน่ใจต้องต่อmcpหรืออะไรมั้ย ที่จะช่วยให้เราง่ายขึ้น https://github.com/line/line-bot-mcp-server)

### **ระบบจัดการ Template ข้อความ**

* เก็บ template ข้อความ LINE ไว้ใน sheet แยกในไฟล์ Excel ชื่อ `LINE_Templates` เพื่อให้แก้ง่าย มีคอลัมน์:  
  * `TEMPLATE_ID` (เช่น DEFAULT, RATCHATA\_SPECIAL)  
  * `MESSAGE_BODY` (ข้อความหลัก มี placeholder เช่น `{shop_name}`, `{month}`, `{total_amount}`, `{due_date}`)  
  * `LAST_EDITED` (วันที่แก้ล่าสุด)  
* Agent จะมาดึง template นี้ไปใส่ข้อมูลของแต่ละร้านก่อนส่งทุกครั้ง

### **Gate 3 — UI ตรวจสอบข้อความก่อนส่ง**

ระบบแสดงใน Eigent เป็นรายร้านค้าทีละร้าน มีองค์ประกอบดังนี้:

* **ชื่อร้านค้า \+ รหัสห้อง**  
* **ช่อง text ที่ edit ได้** แสดงข้อความที่จะส่งจริง (พนักงานแก้ได้ทันที)  
* **ปุ่ม Copy ข้อความ**  
* **รูปภาพ invoice** (สำหรับร้านที่ต้องการรูปมากกว่า PDF)  
* **ไฟล์ PDF invoice**  
* **ปุ่ม: ส่งร้านนี้ / ข้ามร้านนี้**  
* **ปุ่ม: ส่งทั้งหมดที่เหลือ** (bulk confirm)

---

### **โหมด Manual (ยังไม่มี LINE OA Token)**

* ระบบเตรียม: รูป invoice (export จาก FlowAccount PDF → แปลงเป็น image), PDF invoice, ข้อความที่จัดรูปแบบสวยงามพร้อม copy  
* พนักงานบัญชีใช้ UI ด้านบน copy ข้อความและลากไฟล์ไปส่งใน LINE PC ด้วยตัวเอง  
* Export รูปและ PDF ไว้ที่โฟลเดอร์ `/output/invoices/YYYY-MM/[ชื่อร้าน]/` เพื่อให้ drag & drop ได้ง่าย (ถ้าทำให้ลากรูป,pdf จากeigentไปลงไลน์ได้เลยจะดีมาก เค้าจะได้ไม่ต้องมานั่งเปิดfolderเอง)

### **โหมด Automated (มี LINE\_OA\_TOKEN แล้ว)**

* ระบบตรวจสอบ config ว่ามี `LINE_OA_TOKEN` หรือไม่ (ซึ่งอันนี้อาจต้องทำระบบไหม เช่น ให้userบอกai ว่าสมัครline oa แล้ว tokenคือ… แล้วaiไปทำงานต่อเอง)  
* ถ้ามี: แสดง UI เหมือนเดิมทุกอย่าง แต่เพิ่มปุ่ม "ส่งอัตโนมัติ" ให้กด confirm ครั้งเดียว  
* หลังกด confirm: ระบบวิ่งส่ง LINE Push Message ทีละร้านตาม `LINE_USER_ID` ใน database  
* ส่งเสร็จแล้วแจ้งผลในแชทว่า "ส่ง LINE สำเร็จ X ร้าน / ส่งไม่สำเร็จ Y ร้าน (รายชื่อ...)"

### **ทดสอบ End-to-End ครั้งแรก**

* รันกระบวนการทั้งหมดตั้งแต่ต้นจนจบด้วยข้อมูลจริง 2-3 ร้านค้า  
* บันทึก bug และจุดที่ต้องปรับ

## **สัปดาห์ที่ 6: Polish, Edge Cases & Demo Prep**

**เป้าหมาย:** เก็บงาน ดักจับ error และเตรียม demo

### **Error Handling ที่ต้องครอบคลุม**

**เรื่องมิเตอร์:**

* รูปเบลอ / แสงไม่ดี / มิเตอร์บดบัง → แจ้งเตือนในแชทพร้อมระบุชื่อห้อง  
* ชื่อไฟล์ไม่ตรงรูปแบบ → แจ้งเตือนและรอรูปใหม่  
* เลขมิเตอร์ใหม่น้อยกว่าเก่า (อาจเวียนกลับ หรือกรอกผิด) → flag ให้พนักงานตรวจสอบ  
* มิเตอร์บางห้องหายไป (ช่างลืมถ่าย) → แสดงรายชื่อห้องที่ยังไม่มีรูปในแชท

**เรื่อง FlowAccount:**

* API timeout หรือ error → retry อัตโนมัติ 3 ครั้ง แล้วแจ้งเตือน  
* invoice ซ้ำ (สร้างไปแล้วรอบก่อน) → ตรวจสอบก่อนสร้างใหม่

**เรื่อง LINE:**

* `LINE_USER_ID` ว่าง → ข้ามไปโหมด manual สำหรับร้านนั้น  
* ส่งไม่สำเร็จ → log และแสดงรายชื่อร้านที่ต้องส่งมือ

**เรื่อง Excel:**

* ไฟล์ถูกเปิดค้างอยู่ (file lock) → แจ้งเตือนให้ปิดไฟล์ก่อน  
* format ไฟล์ผิดปกติหลัง save → backup ไฟล์เดิมก่อนทุกครั้ง แล้วค่อย overwrite

### **คู่มือการใช้งาน**

จัดทำเอกสารสั้น ๆ ครอบคลุม:

* วิธีตั้งชื่อรูปมิเตอร์ที่ถูกต้อง (สำหรับช่าง)  
* วิธีเพิ่ม/แก้ไข template ข้อความ LINE ใน Excel  
* วิธีเพิ่มลูกค้าใหม่เข้าระบบ  
* ขั้นตอน approve แต่ละ gate  
* วิธีแก้ปัญหาเบื้องต้นที่พบบ่อย
